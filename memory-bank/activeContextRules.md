# Active Context — правила чекпоинта

Читай перед завершением каждой задачи. Маршрутизация — `index.md`, правила банка — `maintenance.md`.

`local/activeContext.md` — личный снимок работы вне git, не журнал и не источник истины: состояние проекта — код и
`git log`, долги — `defects.md`. Каталог `memory-bank/local/` исключён из git (`.gitignore`).

- **Чекпоинт пишется после каждой задачи** — перед итоговым отчётом, даже если банк больше не менялся; без него задача не
  считается завершённой
- Очищается при старте новой сессии или смене ветки; по ходу работы актуализируется под текущую задачу, не растёт хронологией
- Шапка `[hh:mm][dd-MM-yy] · ветка · HEAD · файлы из git status`, секции Цель/Шаги/Дальше/Дефекты; дефекты — только `ID` из
  `defects.md`; шапка не совпала с `git rev-parse` — файл черновик, состояние проекта — код и `git log`
- Без копий кода: пути, решения и следующий шаг; целевой бюджет — 800 токенов, превышение — повод сжать, а не терять значимое
