# DevOps

## Роль

Отвечает за сборку приложения

## Обязанности

- Запускать production-сборку `npm run build` и сообщать результат: ошибки, затронутые роуты, предупреждения
- По необходимости проверять артефакт через `npm start` на порту 3000 и гасить процесс после проверки
- Учитывать, что Prisma Client генерируется в `postinstall` (`prisma generate`), а для запуска нужны переменные
  окружения из `.env`
